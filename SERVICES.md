# Services Direction

This file defines the public-facing service direction for the portfolio. It is intentionally high-level and does not expose private implementation details.

---

## 1. Local AI Infrastructure Audit

### Focus
- Local AI environment review
- GPU utilization and stability assessment
- Runtime and dependency review
- Bottleneck identification
- Practical optimization roadmap

### Public Positioning
Helping teams make local AI workloads more stable, repeatable, and cost-aware.

### Private Scope
Implementation scripts, exact tuning recipes, and machine-specific settings are not published.

---
